## 🌟 Executive Summary

Version **v0.3.4** represents a major architectural evolution for `token-context-mcp`. Inspired by the **DeepSeek Harness** and **Cordis Framework** (*"Everything is a Plugin"*), this release introduces a unified middleware waterfall, declarative multi-step context batching, exact Tree-sitter AST byte-span elision, and reasoning LLM compatibility, while incorporating the SCIP oracle evaluation suite and JVM/C# static type enhancements from `m14`.

All changes strictly preserve the read-only security boundary and have been verified against the new **Golden Contract Test Suite** with zero regressions.

---

## 🚀 Key Features & Architectural Enhancements

### 1. Cordis Kernel & Unified Middleware Waterfall (`kernel/`)
- **`InvocationContext`**: Replaces ad-hoc argument passing with a standardized execution context carrying caller identity, spatiotemporal constraints, reactive coeffects, and reversible effect records (`EffectRecord`).
- **Sequential Middleware Waterfall**:
  - `AuthMiddleware`: Enforces environment-bound caller identity, rejects unauthorized impersonation, and isolates the reserved `admin` role.
  - `GovernanceMiddleware`: High-speed in-memory verification for emergency halt, agent pause/block state, policy restrictions (`READ_ONLY` / `CUSTOM`), and sliding-window rate limits.
  - `ExecutionMiddleware`: Dispatches tool execution and translates domain exceptions into standard structured MCP error envelopes.
- **Ultra-low latency**: Internal dispatch overhead is **0.0109 ms/call** (>91,000 calls/sec).

### 2. Declarative Context Batching (`retrieve/batch.py`)
- Provides multi-step chained context queries in a single tool turn (e.g., `find_symbols` ➔ `get_symbol_context` ➔ `get_impact_slice`), slashing client-server network/turn delays.
- Dynamic reference templating: sub-operations can consume previous outputs (e.g. `"$prev.data.symbols[0].symbol_id"`).
- Strict read-only guarantee: attempts to execute mutating or administrative tools within a batch are immediately rejected.

### 3. AST Byte-Span Body Elision (`sampling/skeleton_hybrid.py`)
- Replaces legacy line-based regex splitting with byte-accurate Tree-sitter AST ranges (`body_start_byte`/`body_end_byte`).
- Natively supports **Python, Java, TypeScript/JavaScript, Go, and C#**.
- Guarantees 100% syntactic preservation of class declarations, method signatures, decorators, and imports while eliding irrelevant function bodies.

### 4. Reasoning LLM Support (`sampling/router.py`)
- Automatically strips `<think>...</think>` internal reasoning blocks from thinking models (such as DeepSeek R1, Qwen-QwQ, and Claude extended thinking) prior to markdown un-fencing and Pydantic validation.
- Completely prevents JSON parsing and schema validation crashes.

### 5. TOML Roundtrip Preservation (`config.py`)
- Uses `AppConfig.extra` to preserve unrecognized configuration tables (e.g. `[plugins]`, `[harness]`) during `register`, `unregister`, `update`, and `save_config` operations.

### 6. SCIP Oracle & Static Type Analysis (Merged from `m14`)
- Integrated SCIP oracle evaluation harness (`evals/edge_oracle_eval.py`, `evals/scip_to_gold.py`).
- Enhanced JVM/C# call resolution: static types, bounds, constructor chaining, and `await` unwrapping.

### 7. Golden Contract Test Suite (`tests/golden/`)
- Snapshot contract verification for `tools/list` across all 4 server configurations (`core`, `+extensions`, `+admin`, `+extensions+admin`) and 2 schema profiles (`default`, `gemini_safe`).
- Deterministic sanitized output regression snapshots for standard retrieval tools.

## 📦 Upgrade Guide

No index rebuild is required for this upgrade. Existing SQLite snapshots in `indexes/`, `memory.sqlite`, `governance.sqlite`, and `repos.toml` remain 100% compatible.

```powershell
# In PowerShell:
cd D:\AI\token-context-mcp
git pull origin main
uv sync --all-extras
uv run pytest tests/golden/ -v
```

Restart your MCP clients (Claude Code, Antigravity IDE, Cursor, Codex) to load the updated server.
