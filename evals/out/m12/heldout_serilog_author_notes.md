# heldout-serilog author notes (self-review)

Author session: read `src/Serilog/` (113 files, tag v4.4.0) directly; no token-context tool, no retrieval/ranking script used. Only `lint_tasks.py`, `lint_packet_tasks.py`, `verify_bench_gold.py` were run (all clean: 30 tasks, 10 packet tasks, missing_gold = 0).

Generated by a scratch script that looks up each `def_line` with a regex on the signature line. `def_line` = the line holding the member name/signature (for members with attributes the index span starts at the first attribute line, e.g. t23 ApplyDirectives def 227 vs span 225; same for FindConfigurationMethods, ConvertToType).

## Indexer quirks observed (gold chosen to avoid them)
* Methods whose signature is split by `#if FEATURE_SPAN ... #else ...` (PropertyBinder.Construct*) are NOT in the index, so they are never gold; `PropertyBinder` (class) and `MessageTemplateProcessor.Process` are.
* Nested classes are indexed with the outer class prefix (`PropertyValueConverter.DepthLimiter.*`, `SelfLog.SelfLogFailureListener.*`, `LogContext.ContextStackBookmark.*`).
* Constructors are `Class.Class`.
